IMAGES
======

Files to place here
-------------------
- MYELIN splash/loading screen
- Launcher background artwork, if used
- Dashboard illustrations
- Empty-state artwork
- COSINE platform artwork or approved logos
- Report branding images
- Other non-icon visual resources

Naming rule
-----------
Use lowercase snake_case names and avoid spaces, for example:
- myelin_splash.png
- launcher_background.webp
- cosine_empty_state.png

Packaging note
--------------
Only include files that the final application is permitted to redistribute.
