ICONS
=====

Files to place here
-------------------
- MYELIN application icon
- Launcher/navigation icons
- MIRL icon
- COSINE icon
- SINE icon
- Metric Hub icon
- Science Lab icon
- Profile icon
- Education Timer icon
- Minimize, maximize/restore, and close icons if custom assets are used
- Status and notification icons

Recommended formats
-------------------
- SVG for scalable interface icons when supported
- PNG for raster fallbacks
- ICO for the packaged Windows executable/installer where required

Naming rule
-----------
Use lowercase snake_case names, for example:
- myelin_app.ico
- mirl_dashboard.svg
- education_timer.svg
